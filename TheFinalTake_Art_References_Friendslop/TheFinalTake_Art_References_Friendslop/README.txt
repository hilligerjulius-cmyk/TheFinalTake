THE FINAL TAKE — FRIENDSLOP ART REFERENCE PACK

This pack contains eight matching visual references for The Final Take. They define a unified, playful low-poly 3D Friendslop look for the crew, costumes, studio layout, lobby, director's office, shark soundstage, flooded finale and production props.

Use the images as visual direction and composition references when building the Unreal demo. Create actual 3D geometry, materials, characters, props and gameplay; do not use a reference image as a full-screen background or as a substitute for a 3D asset. Keep the playable camera in first person. Other crew members should be visible as stylised characters to each other.

These are concept references, not finished rigged or production-ready game models. Keep all game elements consistent with the same chunky shapes, saturated colours, simple matte surfaces, readable silhouettes and slapstick co-op tone.
